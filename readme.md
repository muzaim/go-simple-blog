# Simple Blog Platform API

RESTful API untuk platform blog sederhana menggunakan Golang, Gin Framework, GORM, dan MySQL.

---

## 🚀 Quick Start

### 1. Clone Repository

```bash
git clone https://github.com/muzaim/go-simple-blog.git
cd go-simple-blog
```

---

### 2. Setup Environment Variables

```bash
cp app/.env.example app/.env
```

---

### 3. Run Application

```bash
docker-compose up --build
```

Server akan berjalan di: `http://localhost:8080`

---

## 🧪 Postman Collection

Import file [`postman_collection.json`](postman_collection.json) di root direktori ke Postman untuk menguji semua API endpoint.
